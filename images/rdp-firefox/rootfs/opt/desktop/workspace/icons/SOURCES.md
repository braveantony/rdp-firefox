# Icon sources

The program icons shown on the cards and the toolbar, copied from the images
of the tools they stand for. They remain the property of their projects.

| File | From |
| --- | --- |
| `vscodium.png` | `/usr/share/pixmaps/vscodium.png` in rdp-vscode (VSCodium), resized to 256 px |
| `jupyterlab.svg` | `share/icons/hicolor/scalable/apps/jupyterlab.svg` in rdp-jupyter (JupyterLab) |

Firefox's icon is read from this image's own `/usr/share/icons/`; the tkadm
icon is drawn by `workspace.py`.
